# 八卦占卜桌面摆件设计方案

## 设计目标

本原型面向 Windows 桌面摆件场景，本阶段只设计外部图标态。核心体验是“静置为太极，悬浮即显盘”。默认态保持图 1 的极简黑白太极图，减少桌面干扰；鼠标悬浮后，通过层层展开和正逆转动形成占卜仪式感。

## 状态设计

1. 初始态：仅显示黑底白色太极图，对应图 1。
2. 悬浮触发：太极自身顺时针旋转，中心尺寸保持不变。
3. 第一层展开：外层展开八个三爻卦象，对应图 2；外层三爻卦象环逆时针转动。
4. 第二层展开：继续展开干支、二十四山等罗盘文字环，对应图 3；新增文字环顺时针转动。
5. 完整展开：扩展为更密集的多层罗盘结构，对应图 4；整体仍保持黑白高对比和圆形桌面摆件形态。

## 视觉原则

- 色彩：只使用黑、白与少量半透明白线，贴近参考图的占卜器物质感。
- 构图：中心太极固定，所有扩展层围绕中心展开，避免视觉重心漂移。
- 动效：中心顺时针、第一层逆时针、后续层顺时针，形成“内外相生、阴阳交错”的运动逻辑。
- 桌面适配：默认态面积小，悬浮后扩展；适合做成透明窗口、置顶窗口或无边框小组件。

## 交互说明

- 鼠标悬浮或键盘聚焦：播放展开序列。
- 鼠标离开或失焦：收回到图 1 初始态。
- 单击：预留为进入内部界面的入口，本阶段不展开内部面板。
