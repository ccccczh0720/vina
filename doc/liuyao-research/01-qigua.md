# 01 起卦资料整理

## 1. 背景

《易传·系辞上》保存了蓍草筮法的古典说明，其中包含“大衍之数”“四营而成易”“十八变而成卦”等内容。这个体系是《周易》占筮的古典来源，但计算过程较复杂，不适合作为桌面悬浮窗第一版的主流程。

当代六爻纳甲应用更常见的是金钱卦：用三枚钱币或硬币连续摇六次，从下往上生成初爻到上爻，再据动爻生成变卦。现代在线排盘工具也普遍支持随机摇卦、手动起卦、时间起卦、报数起卦等方式。

## 2. 第一版建议

Vina 第一版采用“自动随机模拟三枚铜钱摇卦”：

1. 用户输入问题类型和问题文本。
2. 点击“自动起卦”。
3. 系统生成六次随机结果。
4. 六次结果从下往上记录为初爻、二爻、三爻、四爻、五爻、上爻。
5. 每一爻记录阴阳、动静、原始摇卦值。
6. 动爻反转后生成变卦。
7. 先展示卦象预览，由用户确认后再进入排盘和解卦。

## 3. 爻值编码

建议内部使用传统数值 `6/7/8/9`，同时兼容 UI 简写。

| 内部值 | 名称 | 阴阳 | 动静 | 本卦爻 | 变卦爻 |
|---:|---|---|---|---|---|
| 6 | 老阴 | 阴 | 动 | 阴爻 | 阳爻 |
| 7 | 少阳 | 阳 | 静 | 阳爻 | 阳爻 |
| 8 | 少阴 | 阴 | 静 | 阴爻 | 阴爻 |
| 9 | 老阳 | 阳 | 动 | 阳爻 | 阴爻 |

现代排盘工具也常见 `0/1/2/3` 输入方式，可作为 UI 或导入兼容：

| 兼容值 | 对应 |
|---:|---|
| 0 | 老阴动爻 |
| 1 | 少阳静爻 |
| 2 | 少阴静爻 |
| 3 | 老阳动爻 |

## 4. 随机模拟方式

可为每次摇卦生成三枚硬币，每枚取阳/阴两面。推荐实现时不把“正面/背面”的文化定义写死为判断核心，而是抽象为 `coinFace`，最终只落到 `6/7/8/9`：

```ts
type YaoValue = 6 | 7 | 8 | 9;

interface CastLine {
  position: 1 | 2 | 3 | 4 | 5 | 6;
  value: YaoValue;
  yinYang: "yin" | "yang";
  moving: boolean;
}
```

若采用“阳面记 3、阴面记 2”的常见算法：

- `2 + 2 + 2 = 6`，老阴。
- `2 + 2 + 3 = 7`，少阳。
- `2 + 3 + 3 = 8`，少阴。
- `3 + 3 + 3 = 9`，老阳。

## 5. 本卦、变卦与上下卦

六爻从下到上排列：

- 第 1-3 爻为下卦、内卦。
- 第 4-6 爻为上卦、外卦。
- 本卦由六爻原始阴阳组成。
- 变卦由动爻阴阳反转、静爻保持不变后组成。

观象预览至少应显示：

- 六爻图形。
- 本卦名称。
- 变卦名称。
- 动爻位置。
- 起卦时间。
- 问题类型与问题文本。

## 6. 后续可扩展起卦方式

第一版之后可增加：

- 手动铜钱起卦：用户逐爻输入 `6/7/8/9` 或 `0/1/2/3`。
- 报数起卦：输入上数、下数，按除 8 取上下卦、除 6 取动爻。
- 时间起卦：按年/月/日/时或农历时间生成上下卦和动爻。

这些方式涉及不同流派口径，建议作为“可选模式”，并在界面上保留算法说明入口。
