# 六爻起卦、观象、解卦资料整理

本文档夹整理桌面悬浮窗内“起卦、观象、解卦”功能所需的基础资料和实现口径。

## 文件说明

- `01-qigua.md`：起卦方法、爻值编码、本卦与变卦生成。
- `02-guanxiang.md`：观象阶段应展示的卦象、爻位、动爻、世应、六亲六神等信息。
- `03-jiegua.md`：规则解卦的判断顺序、用神、世应、旺衰、动爻关系。
- `04-product-notes.md`：落到 Vina 桌面悬浮窗的 MVP 流程、数据字段和边界说明。
- `sources.md`：本次查阅的资料链接与用途。

## 资料分层

1. 经典依据：以《周易》《易传·系辞上》为“卦、爻、象、变、筮”的基础依据。
2. 六爻纳甲体系：以文王卦/金钱卦、纳甲、世应、六亲、六神、月建日辰等规则为应用体系。
3. 现代排盘工具与教程：用于确认当代产品常见输入方式、盘面字段、用户流程。

## 实现原则

- 第一版优先做“自动起卦 + 卦象确认 + 排盘 + 规则解卦”。
- 自动起卦只负责随机生成六爻，不参与判断好坏。
- 规则解卦先给可追溯的结构化结论，再交给 AI 润色；AI 不改动本卦、变卦、用神、世应、旺衰等核心判断。
- 卦象内容属于传统文化与娱乐辅助信息，不应包装成确定性预测。
