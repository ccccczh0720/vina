# 03 解卦资料整理

## 1. 解卦的总体顺序

六爻纳甲解卦通常不是只看卦名，而是综合本卦、变卦、动爻、世应、六亲、用神、月建、日辰、旬空、五行生克等信息。

Vina 第一版可采用以下规则顺序：

1. 按问题类型确定用神。
2. 找到用神所在爻；若有多个候选，按规则确定主用神。
3. 判断用神旺衰：看月建、日辰、生扶、克害、旬空、月破。
4. 判断世爻状态：世爻代表求测者自身或当前主观状态。
5. 判断应爻状态：应爻代表对方、环境、外部响应。
6. 判断世应用神关系：生、克、合、冲、比和。
7. 判断动爻：动爻对用神、世爻、应爻的作用。
8. 判断变爻和变卦：看事情变化方向。
9. 输出总论、用神、世应、动爻、建议。

## 2. 用神

用神是所问事项在卦中的代表爻。第一版可按问题类型建立简化映射。

| 问题类型 | 主用神 | 说明 |
|---|---|---|
| 事业/职位/考试 | 官鬼、父母 | 官鬼看职位压力和名位，父母看文书、资质、考试材料 |
| 财运/交易 | 妻财 | 看钱财、收益、交易标的 |
| 感情/关系 | 男测多看妻财，女测多看官鬼；通用版可看应爻与关系用神 | 第一版若不收性别，可用“应爻 + 关系用神”保守处理 |
| 健康 | 世爻、官鬼、子孙 | 世爻看自身，官鬼看病患压力，子孙看解忧恢复 |
| 合作/对方态度 | 应爻 | 应爻代表对方、响应方 |
| 一般问事 | 世爻、应爻、动爻、与问题语义匹配的六亲 | 适合不明确问题 |

## 3. 世应

世爻和应爻是解卦中对“自我与对象”的基本定位：

- 世爻：求测者、自身、当前处境、主观掌控。
- 应爻：对方、外部环境、事件响应、合作对象。

简化判断：

| 关系 | 倾向 |
|---|---|
| 世应相生 | 双方关系较顺，容易形成配合 |
| 应生世 | 外部助我，对方或环境有利 |
| 世生应 | 我方付出较多，主动性强但消耗大 |
| 应克世 | 外部压力较强，对方制约我 |
| 世克应 | 我方能控局，但也可能冲突 |
| 世应相冲 | 关系不稳、节奏相背 |
| 世应相合 | 有连接、合作、牵连，需结合旺衰判断好坏 |

## 4. 月建、日辰、旬空

月建与日辰用于判断爻的旺衰和现实力量：

- 月建：代表当月时令，对爻的旺衰影响大。
- 日辰：代表当日力量，可生、克、冲、合卦中爻。
- 旬空：表示暂时落空、不实、未到位；若逢冲、值日、出空等，可能转实。
- 月破：被月建冲破，通常视为受损，需要结合动静与生扶判断。

第一版可以先做粗粒度评分：

| 条件 | 分值建议 |
|---|---:|
| 用神得月建生扶/同五行 | +2 |
| 用神得日辰生扶/同五行 | +1 |
| 用神被月建克冲 | -2 |
| 用神被日辰克冲 | -1 |
| 用神旬空 | -1 |
| 用神发动且化生/化进 | +1 |
| 用神发动且化克/化退 | -1 |

评分只作为文案层级依据，不应直接展示成“准确率”。

## 5. 动爻

动爻代表变化、触发点、事情正在发生作用的部分。

判断优先级：

1. 动爻是否为用神。
2. 动爻是否生克用神。
3. 动爻是否生克世爻或应爻。
4. 动爻化出之爻对原爻是生、克、合、冲还是回头生克。
5. 多动爻时，优先看贴近用神、世爻、应爻的动爻。

文案输出可以分为：

- “主要推动力”：对用神最有影响的动爻。
- “阻力来源”：克用神、冲世爻、使关系失衡的动爻。
- “变化方向”：动爻化出后对本事是增益还是削弱。

## 6. 六亲

六亲来自五行相对关系，可用于表达事项类别：

| 六亲 | 常见象意 |
|---|---|
| 父母 | 文书、合同、证件、房屋、长辈、保护、消息 |
| 兄弟 | 同辈、竞争、消耗、朋友、分财 |
| 子孙 | 子女、快乐、解除、产品、结果、医药恢复 |
| 妻财 | 钱财、资源、交易、妻子/伴侣之一类象 |
| 官鬼 | 职位、压力、规则、疾病、风险、丈夫/对象之一类象 |

第一版文案不宜过度细化私密关系，尤其感情类可采用中性说法。

## 7. 六神

六神常作为象意补充：

| 六神 | 常见辅助象 |
|---|---|
| 青龙 | 喜庆、顺遂、名誉、正面助力 |
| 朱雀 | 信息、口舌、文书、表达 |
| 勾陈 | 阻滞、田土、旧事、拖延 |
| 螣蛇 | 虚惊、疑虑、缠绕、反复 |
| 白虎 | 冲突、损伤、压力、强硬 |
| 玄武 | 隐情、暗处、欺瞒、流动 |

六神不建议单独决定吉凶，只用于修饰“为什么呈现这种象”。

## 8. 第一版解卦输出结构

```ts
interface Interpretation {
  summary: string;
  usefulGod: {
    relation: string;
    linePosition: number;
    strength: "strong" | "neutral" | "weak";
    text: string;
  };
  selfOther: {
    selfLine: number;
    otherLine: number;
    relation: string;
    text: string;
  };
  movingLines: Array<{
    position: number;
    effect: "support" | "block" | "mixed" | "neutral";
    text: string;
  }>;
  advice: string[];
  ruleTrace: string[];
}
```

`ruleTrace` 用于保存结构化判断依据，便于调试和防止 AI 润色改变核心结论。
