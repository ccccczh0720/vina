# 功能列表

## 一、桌面摆件外部图标

目标：在 Windows 桌面展示一个低干扰、可交互的八卦罗盘摆件。

功能：

- 默认显示太极八卦图标。
- 鼠标悬浮后由内向外展开罗盘外环。
- 支持蓝白赛博风外层视觉。
- 支持中心太极顺时针旋转。
- 支持八卦三爻环和外层罗盘环正逆向旋转。
- 点击摆件打开六爻功能悬浮窗口。
- 支持窗口拖拽移动。
- 支持始终置顶。
- 支持窗口位置记忆。
- 支持透明背景和无边框窗口。

原型位置：`doc/floating-widget`

## 二、六爻起卦悬浮窗口

目标：点击桌面摆件后打开功能窗口，完成六爻起卦排盘和解卦。

功能：

- 悬浮窗口展示，不占满屏幕。
- 支持关闭、最小化、拖拽。
- 输入要问的问题。
- 选择问题类型：事业、财运、感情、健康、学业、其他。
- 点击“起卦”生成排盘。
- 展示本卦。
- 展示变卦。
- 展示动爻。
- 展示月建、日辰、旬空。
- 展示六爻排盘表。
- 排盘表包含六神、六亲、本卦、动爻、变卦、世应。
- 展示卦象判断。
- 展示用神分析。
- 展示行动建议。

原型位置：`doc/liuyao-feature`

## 三、起卦方式

第一版：

- 自动起卦：根据时间或随机数生成六爻。

后续扩展：

- 手动铜钱起卦：用户输入六次铜钱结果。
- 手动指定卦象：用户直接选择本卦和动爻。
- 历史问题再次起卦。

## 四、排盘能力

第一版必须实现：

- 六爻阴阳生成。
- 动爻生成。
- 本卦计算。
- 变卦计算。
- 六神排布。
- 六亲排布。
- 世应标注。
- 月建、日辰、旬空。

后续增强：

- 纳甲完整规则。
- 伏神。
- 飞神。
- 卦宫。
- 用神推荐。
- 旺衰判断。
- 冲合刑害判断。

## 五、解卦能力

第一版：

- 根据问题类型选择用神。
- 根据世应关系输出基础判断。
- 根据动爻输出变化趋势。
- 输出简短行动建议。

后续增强：

- 规则引擎细化。
- 解卦置信度。
- 时间应期判断。
- 多轮追问。
- AI 自然语言润色。

## 六、历史记录

第一版：

- 保存每次问卦时间。
- 保存问题文本。
- 保存问题类型。
- 保存排盘结果。
- 保存解卦结果。

后续增强：

- 历史列表搜索。
- 按类型筛选。
- 收藏记录。
- 导出记录。

## 七、设置

功能：

- 摆件大小。
- 摆件位置。
- 是否置顶。
- 动画速度。
- 是否开启展开动画。
- 默认起卦方式。
- 是否开机启动。

## 八、交付目标

第一阶段交付：

- Windows 桌面摆件。
- 点击后打开六爻起卦悬浮窗口。
- 可完成一次完整的问事、起卦、排盘、解卦流程。
- 本地保存历史记录。

第二阶段交付：

- 完整六爻规则。
- 更细的解卦规则引擎。
- 设置面板和托盘菜单。
- 打包安装包。
