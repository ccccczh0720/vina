# 六爻起卦排盘悬浮窗口功能设计

本功能是 `doc/desktop-widget/floating-widget` 外部桌面摆件点击后打开的悬浮窗口。窗口不做整页应用，而是作为桌面摆件的功能面板承载问事、起卦、排盘和解卦流程。

## 功能顺序

1. 输入要问的问题，或选择问题类型。
2. 起卦：根据用户选择的起卦方式生成本卦、动爻和变卦。
3. 排盘：展示六爻盘，包括六神、六亲、本卦、动爻、变卦、世应、月建、日辰、旬空。
4. 解卦：结合问题类型、用神、世应、动爻、月日旺衰输出解释和建议。

## 页面结构

- 左侧流程栏：问事、起卦、排盘、解卦。
- 问事输入区：问题文本框和类型选择。
- 起卦结果区：本卦、变卦、动爻、月建、日辰、旬空。
- 排盘区：六行爻位表格，从上爻到初爻展示。
- 解卦区：卦象判断、用神分析、行动建议。

## 起卦方式

后续建议支持三种方式：

- 自动起卦：用户输入问题后系统按时间或随机数生成。
- 手动起卦：用户手动输入六次铜钱结果。
- 指定卦象：高级用户直接选择本卦和动爻。

## 解卦输出

解卦结果应分层展示：

- 总论：一句话说明吉凶趋势和关键点。
- 用神：根据问题类型匹配用神并判断强弱。
- 世应：判断本人、对方、环境的关系。
- 动爻：说明变化点、触发条件和时间线。
- 建议：给出可执行行动建议。
