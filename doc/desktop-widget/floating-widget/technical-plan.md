# 八卦占卜 Windows 桌面摆件技术实现方案

## 推荐技术栈

建议使用 Tauri 或 Electron 承载前端原型。若优先考虑轻量、低内存和 Windows 原生体验，推荐 Tauri；若后续需要大量 Node.js 能力和更成熟的桌面生态，可选 Electron。本阶段先实现外部图标态，点击后的内部界面后续再单独设计。

前端层使用 HTML + CSS + SVG + JavaScript：

- SVG 绘制太极、八卦、干支文字环，便于缩放和保持清晰。
- CSS Animation 负责正逆旋转、透明度和缩放展开。
- JavaScript 负责状态编排、悬浮触发、展开计时和配置化生成罗盘文字。

## 窗口实现

桌面摆件窗口建议配置为：

- 无边框窗口：隐藏系统标题栏。
- 背景透明：只显示圆形八卦主体。
- 置顶可选：提供“始终置顶”配置。
- 鼠标穿透可选：未悬浮时可开启穿透，悬浮或热区触发时关闭穿透。
- 位置记忆：保存窗口坐标、缩放比例、是否置顶。

## 模块拆分

1. `renderer/BaguaWidget`：负责 SVG 绘制与状态展示。
2. `renderer/motionController`：负责 hover、展开、收起和点击入口事件等状态机。
3. `renderer/luopanData`：维护八卦、天干、地支、二十四山、六十甲子等文本数据。
4. `desktop/windowController`：负责无边框、透明、置顶、拖拽、位置记忆。
5. `settings/store`：保存用户配置，如尺寸、速度、展开层级、开机启动。

## 状态机

建议定义四个状态：

- `idle`：图 1，仅显示太极。
- `hovering`：太极顺时针转动。
- `trigramExpanded`：图 2，八卦环展开并逆时针转动。
- `calendarExpanded`：图 3，干支环展开并顺时针转动。
- `fullExpanded`：图 4，完整罗盘展开。

状态转换由 hover 事件触发，内部用定时器或动画事件串联。点击外部图标只派发进入内部界面的事件，不在本阶段展示面板。生产版本建议用可取消的状态机，避免频繁移入移出导致动画状态错乱。

## 关键实现点

- 中心太极尺寸固定：只对外层环做缩放和透明度动画，中心图形独立旋转。
- 多层转动互不干扰：每一层 SVG 使用独立 `<g>` 容器，分别绑定 clockwise / counter-clockwise 动画。
- 文本可读性：文字沿圆环径向排布，字号随环层变化，不随窗口宽度无限缩放。
- 性能：SVG 元素数量控制在几百级，CSS transform 使用 GPU 友好的旋转，不频繁重排。
- 可配置：旋转速度、展开延迟、展开层级、默认尺寸都放入配置对象。

## 交付路径

1. 先用 `doc/index.html` 确认视觉、层级、方向和节奏。
2. 将 SVG 绘制逻辑迁移到 Tauri/Electron renderer。
3. 增加透明无边框窗口、拖拽、置顶、位置记忆。
4. 增加设置面板和托盘菜单。
5. 打包 Windows 安装包，补充开机自启动与用户配置持久化。
